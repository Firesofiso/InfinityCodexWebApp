# Feature Specs

This folder contains implementation-focused feature documents.

Use these docs to drive async agent work without re-explaining context in every thread.

## How To Use These Docs

1. Open the feature doc you want to work on.
2. Confirm the scope and acceptance criteria.
3. Tell the agent to implement only that feature doc unless explicitly expanded.
4. Update the doc status and notes after each implementation slice.

## Document Template

Each feature doc should include:

- Goal
- User value
- In scope
- Out of scope
- Data sources and ownership
- API/backend requirements
- Frontend/UI requirements
- Validation and acceptance criteria
- Open questions
- Status and next slice
